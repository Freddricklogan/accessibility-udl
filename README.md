# Accessibility & UDL Toolkit for Educators

WCAG 2.2 accessibility and Universal Design for Learning — accessible documents and video, the full UDL guidelines — with a live self-audit scorer and a color-contrast checker. The page itself is built to WCAG standards.

## ▶ Live demo

**https://freddricklogan.github.io/accessibility-udl/**

A single, self-contained interactive resource — open the live demo above, or open `index.html` locally in any browser (no build step, no dependencies).

## About

Part of a library of rigorous, graduate-level educational resources by Freddrick Logan spanning research methods, educational policy and leadership, higher education, teaching, instructional design, and accessibility. Browse the full hub: **https://freddricklogan.github.io/resources/**
